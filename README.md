# 🚀 AWS Production Platform

> Production-grade AWS Platform Engineering project built from scratch.

## 👨‍💻 About This Project

This repository documents my journey of designing, building and operating a production-style cloud platform using modern Platform Engineering and Site Reliability Engineering (SRE) practices.

The objective is not only to learn AWS services but to understand the architectural decisions, operational practices and engineering principles behind production cloud platforms.

---

# 🎯 Project Goals

- Learn AWS from first principles
- Master Terraform (Infrastructure as Code)
- Build Kubernetes on Amazon EKS
- Implement GitOps using Argo CD
- Design production-ready AWS networking
- Build observability with Prometheus & Grafana
- Learn SRE principles including SLIs, SLOs and Error Budgets
- Build CI/CD pipelines
- Document architecture and engineering decisions
